# Ignite
_A website for a potential YSWS: for hackclubbers who don't have personal computers_

Check it out: [ignite-azure-one.vercel.app](https://ignite-azure-one.vercel.app/)

Deploy instructions:
- git clone https://github.com/the-kat-kat/Personal-Website.git
- cd Personal-Website
- npm install
- npm run dev
